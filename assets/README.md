# Solar texture attribution

`solarsystemscope-sun-2k.jpg` is the Solar System Scope equirectangular Sun texture.

- Source: [Solar System Scope texture library](https://www.solarsystemscope.com/textures/)
- License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- Original file: [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Solarsystemscope_texture_2k_sun.jpg)
- Author: Solar System Scope

The texture is used as the Sun’s surface map in the Moon Orbit simulation. Its colors are intentionally tuned/saturated by the source author for visualization.
